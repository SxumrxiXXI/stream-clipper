# stream-clipper

Tools for turning long stream recordings into short captioned vertical clips:
find the moments where live chat spikes, have a model check each one, cut and
caption it, and queue it for posting.

Work in progress. Built on [OpenShorts](https://github.com/mutonby/openshorts)
(MIT), [yt-dlp](https://github.com/yt-dlp/yt-dlp) and
[TwitchDownloader](https://github.com/lay295/TwitchDownloader).
